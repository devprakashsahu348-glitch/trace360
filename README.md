# TRACE360 — Know the journey. Trust the product.

Digital batch records and honest QR trace pages for small food producers.
Producers record each step of a batch (production → quality → packing → dispatch → receipt), attach evidence,
and share a public page that shows only what they approve.

> TRACE360 is a record-keeping and visibility tool. It is **not** a regulator, laboratory or certifier, and a QR code alone does not prove authenticity.

## Stack (all free tiers)
| Part | Tech |
|---|---|
| Website | Static HTML generated by `scripts/build-site.mjs` (SEO pages, no framework), served by **Vercel** |
| Workspace app | Dependency-free JavaScript app at `/app` |
| API | One Vercel Function (`api/[...path].js` → `server/api.mjs`, Node 20+) |
| Database + files | **Neon** PostgreSQL (evidence files are stored in the database, private by default) |
| Email | Any SMTP provider (Gmail App Password works) |
| Payments | Razorpay (INR), one-time 30-day plan payments |

## Run locally (no accounts needed)
```bash
npm install
npm run dev        # builds the site and runs everything at http://localhost:3000
npm test           # builds, then runs API tests and site checks
```
Locally the API uses an embedded database in `.devdb`, and password-reset links are printed in the terminal.
The demo login (`demo@trace360.app` / `Demo@12345`) exists only when `DEMO_LOGIN=true` (default locally, off in production).
